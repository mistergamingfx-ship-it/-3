# Night Watcher (Forge 1.20.1)
Build: install Java 17 + Gradle 8.1-8.8, then run `gradle build`. Jar: build/libs/nightwatcher-1.1.0.jar
(or copy into the official Forge 1.20.1 MDK and drop src/ in).
Test: /summon nightwatcher:watcher  or the spawn egg in the creative menu.
Config: config/nightwatcher-common.toml
